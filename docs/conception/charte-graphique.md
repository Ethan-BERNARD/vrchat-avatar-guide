# Charte Graphique

## 1. Palette de Couleurs
Le système de couleurs s'aligne sur une interface moderne et lisible.

| Rôle | Nom / Référence | Hexadécimal | Usage |
| :--- | :--- | :--- | :--- |
| **Primaire** | Dark Slate | `#0F172A` | Boutons principaux, titres et éléments d'accentuation sombres |
| **Secondaire / Surface** | Cool Gray | `#F1F5F9` | Arrière-plan des cartes et visuels |
| **Fond (Background)** | Blanc | `#FFFFFF` | Arrière-plan principal de la page |
| **Texte Principal** | Charcoal | `#1E293B` | Titres d'articles et corps de texte |
| **Texte Secondaire** | Muted Gray | `#64748B` | Description des tutoriels et filtres |

## 2. Typographie
- **Police principale :** Sans-serif (Inter / Geist).
- **Échelles de tailles :**
  - `H1` : 40px / Bold (Titre principal du Hero)
  - `H2` : 28px / Semi-bold (Titres de sections : *Tutoriels récents*, *Tous les guides*)
  - `H3` : 20px / Medium (Titres de cartes de tutoriels)
  - `Body` : 16px / Regular (Descriptions)
