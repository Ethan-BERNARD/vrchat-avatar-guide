# Liste des Composants (UI Kit)

Inventaire des composants identifiés depuis le wireframe :

## Composants de Structure (Layout)
- **`Navbar`** : Barre de navigation supérieure avec Mega-Menu déroulant.
- **`Footer`** : Pied de page global avec liens de catégorie.

## Composants d'Interface (UI)
- **`Button`** : Bouton d'action principal et secondaire (variantes pleine et contour).
- **`CategoryFilter`** : Liste de filtres latéraux/horizontaux pour les tutoriels (Blender, Unity, Quest...).
- **`CardTutorial`** : Carte d'affichage avec image, tag, temps de lecture, titre et extrait.
- **`Testimonial`** : Bloc de citation / témoignage avec navigation.

## Composants Spécifiques (Métier)
- **`HeroSection`** : Bloc d'en-tête principal avec double bouton d'action.
- **`ProcessSteps`** : Section 3 colonnes illustrant les 3 étapes de création.
- **`PlatformPath`** : Bloc d'orientation bas de page (*Parcours PC* et *Parcours Quest*).
